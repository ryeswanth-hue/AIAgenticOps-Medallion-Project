Architecture

Medallion Data Pipeline

⬡ Bronze

Raw Ingestion

Synthetic e-commerce data generated and ingested with zero transformation. Incidents injected into raw streams.

  • system_metrics.json — 2,016 records
  • transactions.json — 5,000 records
  • app_logs.json — 10,500 records
  • user_events.json — 20,000 records
  • incident_manifest.json — 5 patterns
→
⬡ Silver

Clean & Enrich

Cleaned, normalised records with statistical anomaly detection (Z-score) applied per service.

  • silver_metrics — error_rate derived
  • silver_logs — error_category tagged
  • silver_transactions — failure_reason
  • is_anomaly + anomaly_type flags
  • latency/cpu/error_rate z-scores
→
⬡ Gold

Incident Aggregation

Anomaly windows merged into discrete incidents. AI classifies severity P1–P4 and enriches with context.

  • gold_incidents — open/investigating
  • gold_rca — root cause + timeline
  • gold_remediations — action plans
  • gold_reports — HTML dashboards
  • Severity: P1 critical → P4 info
→
⚡ AI Agents

Multi-Agent AIOps

Claude Opus 5 agents with @tool functions call each other in an orchestrated loop.

  • OrchestratorAgent — coordinates all
  • IncidentDetectionAgent — classifies
  • RCAAgent — root cause analysis
  • RemediationAgent — action plans
  • ReportAgent — HTML dashboard

Multi-Agent System

Agent Definitions & Tools

🔍
IncidentDetectionAgent
Scans Silver anomalies, correlates error logs, classifies severity, and creates Gold incidents.
@tool functions
query_silver_anomalies query_error_logs get_open_incidents create_incident get_service_metric_summary
🧠
RCAAgent
Retrieves metric timelines, log patterns, and correlated failures to identify root cause with confidence score.
@tool functions
get_incident_details get_metric_timeline get_incident_logs get_transaction_failures get_correlated_services save_rca
🛠
RemediationAgent
Combines RCA findings with runbook knowledge to generate immediate actions and long-term engineering fixes.
@tool functions
get_incident_for_remediation get_rca_for_incident lookup_runbook save_remediation
📊
ReportAgent
Aggregates all Gold-layer data, computes KPIs, writes an executive summary, and generates the HTML dashboard.
@tool functions
get_all_incidents get_incident_full_summary get_business_kpis get_service_health_summary generate_html_report
🎛
Orchestrator
OrchestratorAgent — Pipeline Coordinator

Top-level agent that delegates to all four sub-agents in sequence. Uses its own @tool functions to trigger each sub-agent, poll pipeline state, and confirm coverage before generating the final report.

Getting Started

Run the Pipeline

install
$ pip install -r requirements.txt
$ cp .env.example .env
# Add ANTHROPIC_API_KEY to .env
full pipeline
$ python main.py pipeline
# Data gen → Bronze → Silver → Gold → AI
api server
$ python main.py api
# FastAPI at http://localhost:8000/docs
individual agents
$ python main.py detect
$ python main.py rca INC-XXXXXXXX
$ python main.py report
